# HKUST Final Year Project 24-25, KWT2

### Requirements
python==3.11.x  
Node.js

### Webapp Usage Instructions
1. Navigate to the webapp directory
2. Install react with ```npm i react```
3. Start up the frontend with ```npx react-scripts start```
4. Navigate to webapp/src/backend directory
5. Install the necessary modules with ```pip install -r requirements.txt```
6. Start up the backend with ```uvicorn app:app --reload```
